# Research tool use

When working from retained evidence, use its manifest/index and exact source references first.
Then search the selected source or campaign directory. Broaden only when that lookup leaves a
specific gap. `head` limits output, not search work. Use the bash tool's documented `timeout`
argument for local searches that may traverse a large tree. Do not assume an external `timeout`
command exists. A local search timeout is not a target failure or evidence of absence. Do not
stop network executors or impose arbitrary research budgets to enforce a local search limit.

Inspect declared formats and a representative record before writing a parser. Validate parsed
input shapes and counts. Empty defaults, skipped records or truncated output are not successful
comparisons. Preserve the original evidence and distinguish its date from its import date.

Before reporting changed factual conclusions, verify the exact supporting records and separate
observations from interpretations. File hashes establish integrity, not behavior. Follow the
project's existing executor and scope rules. Name the actual missing prerequisite rather than
inventing an approval requirement or interpreting an offline export as execution authority.
